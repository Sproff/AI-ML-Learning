# AI/ML Learning Workspace

A structured, long-term learning archive and portfolio repository for Machine Learning, Deep Learning, and Artificial Intelligence projects.

---

## 🎯 Architecture & Purpose

This workspace is designed to seamlessly unify three environments:

1. **Google Drive** — Long-term personal cloud archive holding complete notebooks, assets, and learning materials.
2. **Google Colab** — Interactive cloud execution environment for running experiments with GPU/TPU support.
3. **GitHub** — Version-controlled portfolio showcasing clean code, documentation, and polished case studies.

---

## 📂 Workspace Structure

```
ai-ml-learning/
├── machine-learning/
│   ├── 01-telco-customer-churn/
│   │   └── telco_customer_churn.ipynb
│   └── 02-brazilian-ecommerce/
│       └── brazilian_ecommerce.ipynb
├── deep-learning/
├── nlp/
├── computer-vision/
├── generative-ai/
├── mlops/
└── projects/
```

### Folder Conventions

- **Sequential Numbering (`01-...`, `02-...`)**: Used within domain folders (e.g., `machine-learning/`) to maintain a clear learning trajectory and progression.
- **Top-Level Domains**: Broad AI disciplines (`machine-learning`, `deep-learning`, `nlp`, `computer-vision`, `generative-ai`, `mlops`).
- **`projects/`**: Dedicated space for cross-functional capstones and end-to-end production pipelines.
